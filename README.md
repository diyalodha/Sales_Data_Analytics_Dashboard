SALES DATA ANALYTICS DASHBOARD

-> Project Overview
This project analyzes 50,000 sales records using Python and Power BI to extract business insights such as sales trends, customer behavior, product performance, and regional distribution.

-> Tools Used
- Python (Pandas, NumPy, Matplotlib)
- Power BI (DAX, Power Query)
- Excel (Data validation)

-> Key Features
- 50,000 synthetic sales records generated using Python
- End-to-end EDA (Exploratory Data Analysis)
- KPI calculations (Sales, Profit, Margin, Orders)
- Interactive Power BI dashboard with 5 pages:
  - Executive Dashboard
  - Product Analysis
  - Product Tooltip
  - Customer Analytics
  - Regional Analytics
- Drill-through and Tooltip functionality
- Dynamic filtering using slicers

-> Business Insights
- Top-performing products identified
- High-value customer segments analyzed
- Regional sales performance mapped
- Customer age group and behavior analysis

-> Project Files
- Python scripts for data generation and analysis
- Power BI dashboard (.pbix)
- Dataset (CSV format)
